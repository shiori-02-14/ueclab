About UEC ラボ

UEC ラボとは

UEC ラボは、オープンラボやオープンキャンパスで「この研究室の居室はどこ？」が分かりにくい、という学生のために作った非公式の研究室ブラウザです。

公式ラボガイドの情報は公開されていますが、号館・部屋から横断して探すのは手間がかかります。本プロジェクトは、すでに公開されている居室やキーワードを組み合わせて、当日キャンパスを歩くときの目安になるようにしています。部屋は変わっていることがあるので、入室の前には公式ラボガイドと各研究室のサイトで確認してください。

このプロジェクトは しおり🔖 が作成・運営しています。電気通信大学の公式なサイトではありません。大学は運営・監修・後援していません。掲載データは公式ラボガイドを参考に定期的に更新しますが、情報の正確性・完全性・最新性は保証しません。連絡・見学・出願の前には必ず公式ラボガイドと各研究室のサイトを確認してください。

運営

運営は しおり🔖 です。他の作品は 作品一覧 を見てください。本サイトに関する連絡は、 GitHub の Issue へお願いします。

データの出典

データの出典と関連ドキュメントは、以下を参照してください。

  • 公式ラボガイド （大学から提供を受けた内部データではありません。以降の更新も公式ラボガイドを参考に定期的に行います）
  • https://www.uec.ac.jp/arc/assets/labs.json（タイトル・キーワード・公開 URL・写真 URL。本文は取り込んでいません）
  • 公開シラバス（居室・公開されている教員メール）
  • GitHub （ソースコード）

運営ポリシー

UEC ラボは、以下のポリシーに基づいて運営されます。

オープンアクセス
すべてのデータは、以下に定める利用規約のもとで、誰でも自由にアクセス、利用、共有できます。
コミュニティ主導
誰もがデータの収集、検証、更新に参加できる仕組みを提供し、継続的な改善を図ります。
情報保護
未公開の顔写真、学内限定の連絡先、成績など、公開されていない個人情報は扱いません。 公式ラボガイドの本文は再掲載しません。 公開シラバス等に載っている教員のメールアドレスは、出典付きで掲載します。 教員写真は公式ラボガイドの公開 URL を参照するだけで、画像ファイル自体はリポジトリに置きません。 公開するのは研究室名・教員名・類・プログラム・キーワード・居室・公式ラボガイドに載っている出身地・公開メール、研究室 HP など公開 URL へのリンク、および公式写真の参照までです。 取り下げの依頼があれば対応します。
情報の収集
大学の公式 Web サイト、または学内機関の公式 Web サイト等から収集された情報をもとにデータを生成し、必要に応じて加筆・修正を行います。収集にあたっては、過度なサーバー負荷を避けるように、リクエスト数や間隔の制御およびローカルキャッシュの利用を行います。
データの更新
掲載データは、公式ラボガイドを参考に定期的に更新します。 ただし本サイトが公式ラボガイドより新しい・正確であることは保証しません。 最新の情報は、必ず公式ラボガイドと各研究室のサイトを確認してください。

データの修正・削除

誤りや不足がある場合、掲載の取り下げを希望する場合は、 GitHub の Issue または Pull Request を作成して報告・修正にご協力ください。運営側でも公式ラボガイドを参考に定期的に更新します。公式ラボガイド本体の修正は、大学の公式窓口へお願いします。

この端末に残る情報

「気になる」研究室とメモは、この端末のブラウザ（localStorage）にだけ保存します。サーバへは送りません。アカウントはありません。

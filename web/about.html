About UEC ラボ

UEC ラボとは

UEC ラボは、電気通信大学の研究室を、配属先探し向けに検索しやすくした非公式のブラウザです。

電気通信大学の学生には、大学生活を支えるアプリケーションを自分たちで作る文化があります。公式ラボガイドの情報は公開されていますが、類・号館・キーワードから横断して探すには手間がかかります。本プロジェクトは、すでに公開されている情報を組み合わせて検索できるようにすることで、研究室選びを少し楽にすることを目指しています。

このプロジェクトは しおり が作成・運営しています。電気通信大学の公式なサイトではありません。大学は運営・監修・後援していません。情報の正確性や完全性は保証しないため、連絡・見学・出願の前には必ず公式ラボガイドと各研究室のサイトを確認してください。

運営

運営は しおり です。他の作品は 作品一覧 を見てください。本サイトに関する連絡は、 GitHub の Issue へお願いします。

運営ポリシー

UEC ラボは、以下のポリシーに基づいて運営されます。

オープンアクセス
すべてのデータは、以下に定める利用規約のもとで、誰でも自由にアクセス、利用、共有できます。
コミュニティ主導
誰もがデータの収集、検証、更新に参加できる仕組みを提供し、継続的な改善を図ります。
情報保護
未公開の顔写真、学内限定の連絡先、成績など、公開されていない個人情報は扱いません。 公式ラボガイドの本文、教員の顔写真、メールアドレスも再掲載しません。 公開するのは研究室名・教員名・類・プログラム・キーワード・居室と、研究室 HP など公開 URL へのリンクまでです。 取り下げの依頼があれば対応します。
情報の収集
大学の公式 Web サイト、または学内機関の公式 Web サイト等から収集された情報をもとにデータを生成し、必要に応じて加筆・修正を行います。収集にあたっては、過度なサーバー負荷を避けるように、リクエスト数や間隔の制御およびローカルキャッシュの利用を行います。

データの修正・削除

誤りや不足がある場合、掲載の取り下げを希望する場合は、 GitHub の Issue または Pull Request を作成して報告・修正にご協力ください。公式ラボガイド本体の修正は、大学の公式窓口へお願いします。
